# 002 · Language policy

- **Date:** 2026-11-08
- **Origin:** first draft
- **Status:** accepted

## Question

Which language does the project use in the repository, on GitHub and in the library?

## Short answer

- English is the language of everything in the repository: code, comments, docs, decisions, file and folder names.
- English is also the language on GitHub: issues, PRs, commits and reviews.
- The library's built-in interface text (sidebar, settings, tabs, the 404 page) is in English. The pages of a portfolio are written by its owner, in any language.

## Why

- It follows the same rule as Yoko, Gaku and Haru, so the projects read the same way.
- Kami is a public npm package. English docs and messages reach the widest group of people who might use it.

## Consequences

- The README, the CLI output and the template are in English.
- The library has no i18n for now. Translating the built-in text would be a feature issue of its own.
